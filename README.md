# Obliphur's Integrated Terminal (OIT)
(并非integrated terminal( )
***
你是否曾在各种无意义的小事上浪费时间,你是否曾对overwhelming的媒体流感到疲惫或厌倦...

这个应用的核心功能正是为解决这个问题而生.
你可以设置你的每日上网时间,(设置上网前冷静期),集中处理问题,杜绝零散的时间浪费.
附带的一些计时器会定时提醒你反思你刚刚做了什么,应该休息多久.

如果你你在中考/高考/考研或其他任何考试 这个计时器搭配离线网课可以比较明显地降低分心的可能性.

这可能会大幅改变你的生活习惯.

## ⚠️ 警告

> **请在安装前阅读以下内容。**

- 本项目**包含 AI 生成的代码**。(其实下面的简介也是AI生成的)
- 程序包含**关闭网卡等强制性断网措施**；如需更温和的方式，可将 `config.py` 中的 `BLOCK_MODE` 改为 `"firewall"`。
- **紧急情况（需要立刻恢复网络）请使用程序内置的 Uninstall 功能。**

## 功能概览

| 模块 | 功能 |
| --- | --- |
| **⏱ Timer** | 开始 / 结束专注，实时显示建议休息时长，记录今日与昨日学习时长 |
| **🌐 Network** | 申请联网（需填写时长与原因）→ 冷静期 → 自动放行 → 额度耗尽或手动结束即断网 |
| **(可开关) 📝 Hour Log** | 每整点发出提示音，记录过去一小时做了什么；超时未填自动记为 `Sleeping` |
| **📅 Calendar** | 以日历形式查看每日学习时长 |
| **🗑 Uninstall** | 安全卸载：立即恢复网络并清理数据，供紧急情况或不再使用时使用 |

### 整点日志开关

Hour Log 页右上角提供总开关，可随时开启或关闭整点记录：

- **开启**：整点提示音、填写提醒与超时自动补记（`Sleeping`）均正常工作。
- **关闭**：不响铃、不提醒、不写入任何记录，输入框置灰；侧栏入口显示 `(off)` 标记。
- **状态记忆**：开关状态与日志一同保存，重启程序后沿用上次选择。
- **重新开启**：从**当前小时**开始记录，关闭期间的时段保持空白，不做任何补记。

## 系统要求

- **操作系统**：Windows 10 / 11（断网功能依赖 Windows 管理员权限与 PowerShell）
- **Python**：3.10+（推荐 3.11 / 3.12 / 3.13）
- **依赖**：仅使用 Python 标准库（`tkinter`、`ctypes`、`subprocess` 等），无需安装第三方包

> 非 Windows 平台可以运行界面，但联网控制功能会自动跳过。

---

## 安装与运行

1. 将本项目解压到任意目录。
2. 确认已安装 Python，且 `python` / `pythonw` 可在命令行中使用。
3. 双击运行，或在终端中执行：

   ```bash
   python main.py
   ```

4. 程序启动时会自动申请管理员权限（断网功能需要），同意后界面才会出现。

## 默认配置

以下为 `config.py` 中的默认值，可按需修改：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `DAILY_LIMIT` | `2h` | 每日联网额度上限 |
| `COOLDOWN` | `5min` | 申请联网后的冷静期 |
| `BLOCK_MODE` | `adapter` | 断网方式：禁用物理网卡（彻底）或防火墙拦截出站（恢复快） |
| `HOUR_LOG_ENABLED` | `True` | 整点日志的默认开关状态（程序内可随时切换并记忆） |
| `AUTO_TEXT` | `Sleeping` | 超时未填写的自动记录内容 |

## 设计原则

- **fail-closed**：程序**启动、退出与异常时一律断网**，仅在申请通过后短暂放行。
- **可逆**：随时可通过 Uninstall 立刻恢复网络并清除全部数据。
- **数据留在本地**：全部记录仅写入本机，不进行任何上传。
