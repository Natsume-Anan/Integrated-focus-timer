# Obliphur's Integrated Terminal (OIT)

> (并非集成终端...)

你可能遇到过:时间被无意义的琐事消耗/overwhelming的信息流让人感到疲惫/烦躁.本应用的核心功能即针对这一问题:

- 设定每日联网额度与联网前的冷静期,把上网压缩为集中处理,避免零散的时间浪费;
- 上网时间需提前规划,资源需及时收集;
- 附带的计时器定时提醒使用者回顾刚完成的工作,并给出建议休息时长.

如果正在准备中考 / 高考 / 考研或其他考试,该计时器搭配离线网课可较明显地降低分心的可能性.

长期使用可能改变你的生活习惯:'资源管理'的思路会逐步渗透到日常之中,稳定的本地图书馆会带来一种独特的安心感.

## 功能

| 页面 | 作用 |
| --- | --- |
| **⏱ Timer** | 专注计时,结束后给出建议休息时长 |
| **🌐 Network** | 申请制联网:冷静期后自动联网,到点断网;另有快速访问与紧急借贷 |
| **🛡 Rules** | Proxy 模式下的网站 / 应用黑白名单,可让 AI 给出建议 |
| **📝 Hour Log** | 每个整点提示记录上一小时做了什么 |
| **📅 Calendar** | 按日查看学习时长 |
| **📊 Statistics** | 活动与联网理由的时间分布 |
| **⚙ Settings** | 可调参数(含按星期调整联网额度的倍率);多数修改需要等待冷静期才生效 |
| **🗑 Uninstall** | 恢复网络并清理数据 |

断网有两种方式:**Adapter** 直接禁用网卡;**Proxy** 通过系统代理过滤,不读取系统代理的程序不受其限制.

## 运行

- Windows 10 / 11,Python 3.10+,仅用标准库
- 启动时会申请管理员权限(断网需要)

```bash
python main.py
```
