# Obliphur's Integrated Terminal (OIT)

> (并非集成终端...)

你可能遇到过:时间被无意义的琐事消耗/overwhelming的信息流让人感到疲惫/烦躁.本应用的核心功能即针对这一问题:

- 设定每日联网额度与联网前的冷静期,把上网压缩为集中处理,避免零散的时间浪费;
- 上网时间需提前规划,资源需及时收集;
- 附带的计时器定时提醒使用者回顾刚完成的工作,并给出建议休息时长.

如果正在准备中考 / 高考 / 考研或其他考试,该计时器搭配离线网课可较明显地降低分心的可能性.

长期使用可能改变你的生活习惯:'资源管理'的思路会逐步渗透到日常之中,稳定的本地图书馆会带来一种独特的安心感.

## 功能一览

| 页面 | 作用 |
| --- | --- |
| **⏱ Timer** | 专注计时,实时显示建议休息时长,记录今日与昨日学习时长 |
| **🌐 Network** | 申请制联网:冷静期 → 自动放行 → 到点断网;快速访问免冷静期(额度 2 倍消耗);额度不足时可紧急借贷(今天 +1 分钟,明天 -2 分钟) |
| **🛡 Rules** | Proxy 模式下的黑白名单(网站 / 应用);Adapter 模式下规则只保存、不生效 |
| **📝 Hour Log** | 每整点提示并记录上一小时的工作内容;超时未填按设定文本补记 |
| **📅 Calendar** | 以日历形式查看每日学习时长 |
| **⚙ Settings** | 全部可调参数 |
| **🗑 Uninstall** | 恢复网络并清理数据 |

## 配置项

配置均在 **Settings 页**修改。**即时生效项**保存后立刻生效;**每个选项的第一次修改也立即生效**
(相当于免一次冷静期);此后的修改才进入 **48 小时冷静期**
(期间仍按旧配置运行,可随时取消;程序关闭期间照样倒计时)。

### 断网方式(Settings → 断网方式)

| 方式 | 离线时 | 联网时 |
| --- | --- | --- |
| **Adapter**(默认) | 禁用全部物理网卡 | 启用网卡 |
| **Proxy** | 网卡保持开启,由本地过滤代理按名单模式处理 | 同左 |

Proxy 下再选**名单模式**(Rules 页顶部或 Settings → 过滤名单模式),Rules 页只显示当前模式的两张表(网站 / 应用):

| 名单模式 | 离线 | 联网 |
| --- | --- | --- |
| **黑名单模式**(默认) | 默认放行,只拦黑名单里的网站 / 应用 | 同左(与联网额度无关) |
| **白名单模式** | 默认拦截,只放行白名单里的网站 / 应用 | 联网会话中全部放行 |

- 切换名单模式与其它设置一样:第一次立即生效,之后要等 48 小时。另一模式的名单会保留但不生效。
- 加入白名单、移出黑名单(放宽)要等 48 小时;加入黑名单、移出白名单(收紧)立即生效。
  第一次改动名单后的 2 小时是初始化窗口,放宽也立即生效。
- Proxy 模式通过**系统代理**生效:浏览器和大多数遵守系统代理的程序会被过滤,
  **不读取系统代理的程序(部分游戏、客户端、自带网络栈的程序)不受影响** —— 要连它们一起管住请用 Adapter。
- 应用规则靠代理查询连接所属进程(exe 文件名),只对走代理的连接有效。
- 若本来就设置了 HTTP 代理(Clash / v2ray 等),放行的流量会继续转给它;还原时原设置原样恢复。
- 程序关闭后系统代理会保持指向已停止的本地端口(等同于离线)。Uninstall 会还原原来的代理设置。

### AI 名单建议(Rules 页 → 🤖 AI 建议 / ⚙ 模型)

先在 **⚙ 模型** 里选供应商并填 API Key:**Claude / ChatGPT / DeepSeek** 会自动填入 Base URL、协议和常用模型名(模型名可改);
**自定义**则全部留空,Base URL 与模型自己填,协议选 openai(兼容接口)或 anthropic。Key 以明文存在应用数据目录的 `ai_config.json`。

点 **🤖 AI 建议**(按当前名单模式使用对应提示词),每一步都由你确认:

1. 勾选提供什么:已安装应用(名称 + exe 名)、浏览器常访问网站(**只有域名与访问次数**,不读网址 / 标题 / 搜索词);
2. 预览将要发送的完整文本,点「发送」才联网,只发给你选定的那一家;
3. 勾选要采纳的条目,才写入名单(加入白名单仍要等冷静期)。

## 运行

- **系统**:Windows 10 / 11(断网依赖管理员权限与 PowerShell)
- **Python**:3.10 及以上
- **依赖**:仅使用标准库,无需安装第三方包

```bash
python main.py
```

程序启动时会自动申请管理员权限(断网需要)。非 Windows 平台可运行界面,但联网控制会自动跳过。
